# Budget Tracker — Week 3 Visual Design Upgrade ## What I Built This is a **personal budget tracker** web application built with semantic HTML and CSS. This week's update focused entirely on **visual design** — transforming the functional Week 2 layout into a polished, modern interface using a cohesive color palette, custom Google Fonts, refined table and form styling, and intentional use of the CSS Box Model. --- ## Color Palette | Role | Color | Hex | |---|---|---| | Primary (headings, accents) | Blue | `#2563EB` | | Accent (buttons) | Emerald Green | `#10B981` | | Dark (table headers, text) | Slate | `#1E293B` | | Page Background | Light Gray | `#F1F5F9` | | Cards | White | `#FFFFFF` | | Borders | Soft Gray | `#E2E8F0` | --- ## Typography - **Headings:** [Poppins](https://fonts.google.com/specimen/Poppins) — modern, geometric sans-serif for visual hierarchy - **Body text:** [Inter](https://fonts.google.com/specimen/Inter) — highly readable sans-serif optimized for screens --- ## File Breakdown ### `index.html` Contains the full page structure: header with logo, Add Expense form with dropdown, expense history table with 5 data rows, embedded YouTube video, and collapsible help section. The only change from Week 2 is the addition of Google Fonts `` tags in the ``. ### `style.css` Completely redesigned stylesheet featuring: - **CSS Custom Properties** (`:root` variables) for a consistent color palette - **Google Fonts** applied to headings (Poppins) and body (Inter) - **Card-style sections** using padding, border-radius, borders, and box-shadow - **Polished table** with dark header, alternating row colors, and hover effects - **Styled form** with rounded inputs, focus states, and a green action button - **Box Model** used intentionally: margin separates sections, padding creates internal space, borders define edges, border-radius softens corners --- ## How to View 1. Clone or download this repository. 2. Open `index.html` in any modern browser. 3.
